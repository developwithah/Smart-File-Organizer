# 📁 Smart File Organizer

A modern desktop application built with Python and CustomTkinter to automatically organize files into folders based on their file types.

## ✨ Features

- 📂 Organize files by type
- 🖥️ Modern CustomTkinter interface
- 📊 Progress bar
- 📈 Live status updates
- 🔒 Duplicate protection
- 🗂️ Automatic folder creation
- ⚡ Clean architecture
- 🌿 Git version control

## 🛠️ Built With

- Python 3
- CustomTkinter
- OS
- shutil
- pathlib
