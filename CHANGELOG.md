# Changelog

All notable changes to the Smart File Organizer project are documented here.

## Version 3.0

- Prepared Windows executable packaging with PyInstaller.
- Added Inno Setup installer definition and release documentation.
- Added Version 3.0 GitHub Release preparation and regression-testing checklists.
- Added the Windows application icon and real release screenshots.
- Updated project documentation, license, and asset structure.
- Preserved all existing application functionality.

## Version 2.9

- Added professional toolbar and persistent bottom status bar.
- Improved empty-state handling, responsive resizing, and optional icon support.

## Version 2.8

- Added professional menu bar, dashboard, About dialog, and keyboard shortcuts.
- Added visual status indicators and responsive grid layout.

## Version 2.7

- Added Storage Analyzer with category-wise storage analysis.
- Added largest-file and largest-folder reporting.

## Version 2.6

- Added Duplicate File Finder with SHA-256 content detection.
- Added read-only duplicate results.

## Version 2.5

- Added thread-safe Undo Last Operation.

## Version 2.4

- Added folder drag-and-drop support.

## Version 2.3

- Added multithreading and responsive GUI updates.

## Version 2.2

- Refactored the application into clean architecture modules.
